Uber Trip Classification Project

This project builds an end to end data analytics and machine learning pipeline on an Uber trip dataset. The goal is to classify trips as Business or Personal based on temporal, spatial, and behavioral features.

The pipeline includes:

Data exploration and cleaning
Feature engineering and encoding
Handling missing values and outliers
Feature selection using mutual information
Training multiple models including Logistic Regression, Decision Tree, Random Forest, and Gradient Boosting

Logistic Regression achieved the best performance with about 95 percent accuracy and strong balance on the minority class.

This project demonstrates a complete workflow from raw data to model evaluation, highlighting the importance of preprocessing, feature design, and handling class imbalance.
